# Decisions

A log of decisions that change how the app or the team works, so the next
person can see what was decided and why without digging through Slack.

Log a decision when it is hard to reverse, affects more than one pod, or
someone is likely to ask "why is it like this?" later. Small calls that fit in
a PR description do not need an entry.

## How to add one

1. Copy [`0000-template.md`](0000-template.md) to the next free number with a
   short slug, for example `0001-staging-before-main.md`.
2. Fill it in. A few sentences per section is enough.
3. Open a PR. Your pod owner reviews it like any other change.

Entries are not edited after they merge. If a decision changes, add a new
entry and set the old one's status to "Superseded by 00NN".
