# Team

One short intro file per dev team member. Adding yours is your first PR (see the
Local Setup Guide linked from your Linear onboarding ticket).

## Add yours

1. Branch from the Linear ticket's git branch name.
2. Create `docs/team/<first-last>.md`, all lowercase, for example `docs/team/jane-doe.md`.
3. Add only that one file, then open a PR.

## What to put in it

```markdown
# Jane Doe

- **Pod:** Events and check-ins (or "not assigned yet")
- **Fun fact:** ...
- **One thing I want to learn on the team:** ...
```

Keep it short. Do not include a phone number, home address, or anything else
you would not post in a public channel.
